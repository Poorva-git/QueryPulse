QueryPulse combines LLM intelligence, PostgreSQL internals, and enterprise security into a single seamless tool.

Natural Language to SQL

Ask questions in plain English or Hinglish. Powered by Groq's ultra-fast LPU and GPT-o-120B model — generates syntactically perfect, schema-aware PostgreSQL queries every time.

Groq LPU GPT-o-120B Schema-Aware

Zero-Trust AST Security

Every generated SQL is parsed into an Abstract Syntax Tree using sqlglot. DELETE, DROP, UPDATE, pg_sleep, file reads — all blocked before execution. No regex, no guessing.

AST Parsing SQLGlot 8 Attack Vectors

PostgreSQL EXPLAIN Analyzer

Runs EXPLAIN (FORMAT JSON) on every query. Extracts Node Type (Index Scan, Hash Join) and Total Cost — displayed live in the UI. Interviewers love this.

Query Plan Cost Estimation Node Type

Auto Chart Visualizer

Query results are auto-detected and rendered as interactive Bar, Line, or Doughnut charts using Chart.js. Switch between chart types live, export raw data as CSV — no extra config.

Chart.js Bar / Line / Doughnut CSV Export

BYODB — Bring Your Own Database

Recruiters and users can connect their own Supabase, Neon.tech, AWS RDS, or local PostgreSQL database via connection URI — isolated per browser session, never stored.

Session-Isolated Supabase / Neon AWS RDS

AI Executive Insights

After every query, Groq LLM generates a 2-sentence business insight summarizing what the data means — in plain English. Turn raw rows into executive-ready analysis, instantly.

AI-Powered Business Context Groq Fast Inference

Tech Stack

Built with Production-Grade Tools

Clean separation of concerns — every layer has a single responsibility and is independently testable.

Backend Layer
Python + FastAPI
FastAPI — Async REST API with automatic OpenAPI docs
SQLAlchemy — Multi-engine connection pooling with BYODB isolation
SQLGlot — AST-level SQL parsing and security validation
Groq API — LPU-accelerated LLM inference (temperature=0 for determinism)
Frontend Layer
Vanilla JS + Tailwind
Chart.js — Interactive Bar, Line, Doughnut chart rendering
Tailwind CSS — Utility-first responsive dark UI, CDN-loaded
sessionStorage — BYODB session isolation per browser tab
CSV Export — One-click data download from any query result

PostgreSQL 18
dvdrental — 15-table movie rental dataset (default sandbox)
onlinebookstore — E-commerce book database (bonus sandbox)
statement_timeout — 5-second hard limit prevents runaway queries
EXPLAIN (FORMAT JSON) — Query plan cost extracted for every query
